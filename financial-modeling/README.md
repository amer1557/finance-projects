Financial Modeling & Valuation Projects

A collection of Excel-based financial modeling and valuation projects demonstrating practical skills in financial analysis, cash flow modeling, debt structuring, valuation, and investment analysis.

📊 Projects

1. Real Estate Development Model

An Excel-based model designed to analyze the financial performance of a real estate development project.

Key areas covered:

- Development and project costs
- Revenue projections
- Project cash flow analysis
- Profitability analysis
- Investment returns
- Scenario and sensitivity analysis

File: "Real Estate Development Model.xlsx"

2. Debt Waterfall Financial Model

An Excel-based model demonstrating the allocation of cash flows through a structured debt waterfall.

Key areas covered:

- Debt structure and cash flow allocation
- Waterfall calculations
- Principal and interest allocation
- Investor/lender returns
- Cash flow analysis
- Distribution mechanics

File: "Debt Waterfall financial model.xlsx"
